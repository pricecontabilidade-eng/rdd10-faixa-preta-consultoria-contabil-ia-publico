# Consultoria Contábil com IA — Faixa Preta RDD10+

**Projeto:** Consultoria Contábil com IA utilizando Make, Supabase e Camada Ouro.

**Finalidade:** Demonstrar uma arquitetura de automação para processamento de dados fiscais de NF-e, organização de informações na Camada Ouro e geração de diagnósticos gerenciais com apoio de inteligência artificial.

## Arquitetura da solução

Make → Processamento de NF-e → Supabase (Camada Ouro) → Agente de IA → Google Docs.

## Segurança e limitações

Este repositório contém documentação de referência. O projeto original aprovado na Faixa Marrom permanece preservado.

A cópia de demonstração não foi executada. A importação visual dos oito módulos foi realizada, mas o salvamento ficou impedido pela ausência de um Data Store válido.

Não são disponibilizadas credenciais, tokens, chaves de API ou dados fiscais reais.
